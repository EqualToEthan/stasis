应用采用 Flutter 标准分层结构：`lib/main.dart` 通过 `MaterialApp` 注册 `/`、`/wallet-setup`、`/scan-tx` 三个路由作为入口；`lib/screens/` 存放页面组件（首页、钱包设置、骰子熵输入、扫码签名、交易详情、确认签名、导出签名等），全部为 StatefulWidget/StatelessWidget 组合；`lib/services/` 封装业务逻辑，其中 `WalletService` 聚合助记词生成/校验、`cardano_flutter_sdk` 的 HD 钱包创建与 CIP-1852 地址派生、多钱包列表与 PIN 管理，并委托 `SecureStorageService` 使用 `flutter_secure_storage` 持久化敏感数据；`lib/models/` 定义纯数据类 `WalletInfo`、`ColdExport`、`ColdImport`，用于 JSON 序列化与跨设备传输；`lib/widgets/` 当前为空，预留可复用 UI 组件位置。依赖方向严格自上而下：screens → services → models，services 不反向引用 screens，保证 UI 与链上操作解耦。
