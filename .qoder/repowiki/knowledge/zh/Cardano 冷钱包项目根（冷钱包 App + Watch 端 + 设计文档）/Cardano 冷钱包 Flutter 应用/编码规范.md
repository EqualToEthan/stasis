- 每个屏幕以独立文件组织在 `lib/screens/` 下，并通过 `MaterialApp.routes` 集中注册命名路由进行导航。
- 业务逻辑统一收敛到 `lib/services/` 中的 Service 类（如 `WalletService`、`TransactionService`），UI 层仅持有服务实例并调用其异步方法。
- 模型类提供 `fromJson` / `toJson` 工厂方法与静态 `Codec` 辅助类，用于 JSON 序列化与本地存储。
- 敏感数据（助记词、PIN）一律通过 `SecureStorageService` 访问底层 `flutter_secure_storage`，不在 UI 或业务层直接读写。
- 状态更新遵循 `initState` 中调用 `_loadState` 异步加载后 `setState` 的模式，并在回调中使用 `mounted` 守卫避免卸载后 setState。
