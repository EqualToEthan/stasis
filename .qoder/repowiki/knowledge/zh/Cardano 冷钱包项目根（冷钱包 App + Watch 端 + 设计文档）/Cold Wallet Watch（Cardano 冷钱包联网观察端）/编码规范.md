- 每个业务功能拆分为独立文件：`screens/` 按页面分文件、`services/` 按职责分文件、`models/` 每个实体一个文件。
- 服务类通过构造函数注入依赖（如 `WalletService` 注入 `StorageService`、`BlockfrostService` 注入 `http.Client`），便于单元测试替换。
- Model 统一提供 `fromJson` / `toJson` 工厂方法与 `copyWith` 方法，保持 JSON 序列化一致性。
- 屏幕状态变更统一通过 `setState` + `_loading` / `_error` 字段管理加载与错误态，并在异步回调前检查 `mounted`。
- Blockfrost 请求统一通过 `BlockfrostEndpoint.baseUrls` 映射网络名到基础 URL，并以 `project_id` 作为请求头携带 API Key。
- 路由集中在 `app.dart` 的 `MaterialApp.routes` 中以字符串键注册，页面间通过 `Navigator.pushNamed` 配合 `arguments` 传递 `WatchWallet`。
