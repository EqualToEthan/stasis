### 冷钱包 App（coldwallet-app）
- 定义：项目中的离线签名端，Flutter 实现的 Android App，负责助记词生成/导入、BIP-32 Ed25519 密钥派生、扫码接收未签名交易并签名，最终导出 signed-tx JSON/CBOR。不连接网络，不接触 Blockfrost。
- 别名：冷端、离线签名端、coldwallet-app

### watch 端（coldwallet-watch）
- 定义：项目中的联网观察端，独立 Flutter Android App，只保存公开地址与 Blockfrost API Key，负责添加只读钱包、查询余额/UTxO、构建未签名交易并通过二维码/JSON/文件导出给冷钱包签名，最后导入签名结果提交上链。
- 别名：热钱包 App、联网端、coldwallet-watch

### ColdExport / ColdImport
- 定义：冷钱包 App 与 watch 端之间传递交易数据的 JSON 契约，字段包括 version、type（"unsigned-tx" / "signed-tx"）、network、txCbor、summary、txHash 等。两个 App 必须保持字段一致才能完成扫码/文件交换。
- 别名：导出格式、导入格式、交易交换协议

### 掷骰子熵
- 定义：通过物理投掷 256 次六面骰生成 256 bits 随机数（奇数=1、偶数=0），再转换为 BIP-39 24 词助记词。用于替代 SDK 内置伪随机源，提供可验证的真随机种子。
- 别名：dice entropy、骰子助记词

### 只读钱包
- 定义：watch 端中仅保存 Cardano 公开地址与名称的钱包类型，不持有私钥/助记词，因此无法发起交易，只能查询余额、构建未签名交易并导出。
- 别名：观察钱包、watch-only wallet

### Preview 测试网
- 定义：Cardano 的网络之一（mainnet / preview / preprod），本项目 MVP 阶段固定使用 Preview 进行测试，Blockfrost 的 Project ID 按网络绑定，不可跨网混用。
- 别名：preview、testnet
